Como Jogar 🕹️

O computador escolhe um número secreto aleatório entre 1 e 100. 🤫

Você tenta adivinhar digitando seu palpite. 💭

O jogo responde se o número é muito alto ⬆️ ou muito baixo ⬇️.

O contador de tentativas vai diminuindo a cada chute. 🔢

Se você acertar o número, ganha! 🎉

Se acabar as tentativas, o número secreto será revelado. 😢

Regras 📜

Número secreto: 1️⃣ a 1️⃣0️⃣0️⃣

Tentativas máximas: 🔟

Cada palpite fora do intervalo será ignorado ❌

O jogo mostra quantas tentativas você ainda tem a cada chute
